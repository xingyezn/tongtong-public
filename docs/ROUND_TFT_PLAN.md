# 1.28 寸 GC9A01 圆屏接入计划

本文档记录 240×240 SPI 圆屏的接入方案。设备和接线确认前不修改当前板级显示代码。

## 硬件参数与结论

- 驱动芯片：GC9A01
- 分辨率：240×240，RGB 全彩，IPS
- 接口：SPI（RST、CS、DC、SDA/MOSI、SCL/SCK）
- 供电：3～5V；实际接线优先使用稳定的 3.3V 或经确认的 5V 电源
- 未提供独立背光引脚：需确认模组是否背光常亮，以及背光电流

当前固件已经包含 `esp_lcd_gc9a01` 组件、SPI LCD 初始化和 `SpiLcdDisplay`/LVGL 支持，源码中也有 240×240 GC9A01 初始化序列。因此原则上可以复用现有显示框架，不需要另写一套图形渲染系统。

## 与现有硬件的关系

当前 `bread-compact-wifi` 使用 I2C OLED（GPIO41/42），音频使用 GPIO4～7、15/16，电机使用 GPIO8～12，摄像头云台规划使用 GPIO17/21。SPI 屏幕需要另外确认五个可用 GPIO；GPIO 分配不能直接照搬其他板型，必须以当前 PCB 引脚引出情况和原理图为准。

候选分配（仅供接线评估，不得直接视为最终配置）可以使用 MOSI/SCK/CS/DC/RST 分别接 GPIO13/14/3/2/1，但在确认启动绑带、USB、板载 LED 和扩展接口没有冲突前不得使用。

## 软件接入方案

1. 新增或扩展当前板型的 SPI 引脚配置和 GC9A01 Kconfig 选项。
2. 复用 `esp_lcd_new_panel_io_spi()` 与 `esp_lcd_new_panel_gc9a01()`。
3. 配置 RGB565、SPI Mode 0，初始 SPI 时钟从 20MHz 开始，稳定后再提高。
4. 设置旋转、镜像、颜色顺序和圆角安全区域；物理圆屏仍是 240×240 方形像素，四角应避免放置关键文字。
5. 复用现有 LVGL 状态界面，先实现启动画面、网络状态、语音状态和短文本显示。
6. 如果背光可控，再增加背光 GPIO/PWM；若背光常亮，记录实际电流并评估电池续航。

## 分阶段开发

### 阶段一：硬件和裸屏验证

- 确认 VCC 电压、背光电流、SPI 电平和引脚顺序。
- 只显示纯色、色条、网格和文字。
- 验证无花屏、偏移、颜色反转、镜像错误或随机重启。

### 阶段二：LVGL 界面适配

- 将现有 OLED 状态内容迁移到 240×240 布局。
- 调整字体大小、居中方式和圆角安全区域。
- 验证屏幕刷新不会影响音频、Wi-Fi、摄像头和舵机任务。

### 阶段三：交互和功耗

- 验证启动、联网、监听、播放、错误和调试状态显示。
- 如支持背光控制，增加亮度和息屏策略。
- 测试锂电池供电下的电压跌落、SPI 刷屏电流和续航影响。

## 验收标准

- 冷启动和复位后屏幕均能正确初始化。
- 连续刷新 30 分钟无花屏、死机和内存泄漏。
- 所有关键状态文字在圆角区域内可读。
- 屏幕工作时摄像头 USB、语音链路、Wi-Fi、舵机和电机不异常。
- 断电重启后不会因 SPI 外设状态导致启动失败。

## Git 流程

电机功能合并到 `main` 后，从最新 `main` 创建独立分支：

```bash
git switch main
git pull --ff-only origin main
git switch -c feat/round-tft
```

先提交裸屏 PoC，再提交 LVGL 适配和功耗/稳定性测试。每阶段验证通过后再进入下一阶段，设备资料未确认前不提交最终 GPIO 配置。
